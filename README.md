# 婚禮賓客管理系統 Demo

婚禮出席回覆表單＋新人後台的示範網站，作品展示用。

**所有人名、日期、地點與賓客資料皆為虛構**，送出的內容只存在瀏覽器（localStorage），不會傳到任何伺服器。

線上展示：https://ohhshen.github.io/wedding-rsvp-demo/

## 示範內容

- 賓客表單：跑道進度條、依回答切換題目、完成動畫
- 新人後台：即時統計、回覆名單搜尋與篩選、幫長輩代填、CSV 匯出、賀詞隱藏／還原
- 查桌次：輸入姓名查座位並標示在平面圖
- 賀詞牆：賓客留言即時出現在投影牆

單一 `index.html`，不需建置。
